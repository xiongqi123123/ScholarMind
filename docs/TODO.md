# ScholarMind 路线图

设计和每一步的理由见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 0.1.0 已有的

| 部分 | 内容 |
| --- | --- |
| 收论文 | 每天同步 arXiv（按 OAI datestamp 算每日新增，新版本也算）；13 个顶会的导入（OpenAlex、CVF、官方论文集站点、PMLR 四种来源），与 arXiv 记录合并，每周检查新的一届 |
| 打标签 | 领域、方向（可新建，每周合并重复的）、论文类型、关键词、概要；20 篇一批，一批出错时拆开重做；模型接口限流时自动等待 |
| 解读 | 全文一次读完写成文章，引用从 PDF 裁出的原图和表；创新性质判定；手动触发的排在批量任务前面，有进度和失败原因 |
| 阅读 | PDF 与解读并排；摘录批注和每篇一块自由笔记；就一篇论文向模型提问（流式）；摘要逐句中译（第一次打开时生成） |
| 查找 | 来源、领域、方向、类型、创新性质、年份、arXiv 类别筛选，标题和摘要的全文检索；每日新增；收藏和收藏分组 |
| 账号 | 管理员建账号、改角色、重置密码；个人令牌（多个、可命名、可过期）；预设头像 |
| 管理 | 网页上改模型连接（地址和密钥）、模型名、六个提示词 |
| MCP | 搜索、取元数据和解读、按页读原文、笔记 |
| 部署 | 一个镜像一个容器；Gitea Actions 的检查、测试和自动部署脚本 |

## 已知的缺口

- ICLR 2022、2023 拿不到：这两届官方论文集站点上没有，而 OpenReview 拦匿名访问。
- 不开放 PDF 的会议（ICRA、IROS、ACM MM 等），只有 arXiv 上有对应版本的论文能写解读、提问。
- 个别论文在会议站点上的页面已经不存在，导入时跳过并记日志（CVPR 2024 有两篇）。
- 会议记录按 DOI 并入已有论文时，标题以会议版为准。

## 明确不做

见架构文档第 14 节。另外：

- 质量打分：模型给论文打分不可靠，也容易被当成结论。只保留中性的"创新性质"归类。
- OpenReview 适配器：需要账号，且拦匿名访问。
- 比较论文、找研究空白这类工具：交给调用方 Agent 用 MCP 的几个基础工具自己推理。
